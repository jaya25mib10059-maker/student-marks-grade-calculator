# ## Project Overview
# 
# Student Marks & Grade Calculator is a Python-based command-line application. It calculates a student's total marks, percentage, average, highest marks, lowest marks, grade, and final result.
# 
# ## Features
# 
# - Enter student name
# - Enter marks for five subjects
# - Calculate total marks
# - Calculate percentage
# - Calculate average marks
# - Find highest marks
# - Find lowest marks
# - Calculate grade
# - Display PASS or FAIL
